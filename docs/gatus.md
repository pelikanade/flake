# Gatus

[`modules/services/gatus.nix`](../modules/services/gatus.nix) runs
[Gatus](https://gatus.io) from nixpkgs. Its monitors, storage and status page
all come from the YAML document generated by `services.gatus.settings`, so a
monitor set is part of the machine definition rather than a database the
dashboard edits.

## The service

The aspect enables `services.gatus`, binds the web UI to `127.0.0.1:3001` and
keeps history in SQLite at `/var/lib/gatus/data.db`. nixpkgs runs it as the
`gatus` `DynamicUser` with `StateDirectory=gatus` and only `CAP_NET_RAW`, which
the ICMP checks need. No firewall port is opened.

The machine maps the `nsphere-gatus` Tailscale Service to
`http://127.0.0.1:3001` on `tcp:443`, so the daemon terminates TLS for
`https://nsphere-gatus.dwelf-hoki.ts.net/`. Define the Service with that endpoint
in the tailnet's admin console; the local table only forwards to it.

## Endpoints

neko-sphere declares one group, `neko-sphere`:

| Endpoint | Check |
| --- | --- |
| Freezer | `http://127.0.0.1:8080/`, `[STATUS] == 200` |
| Magpie gateway | `http://127.0.0.1:3425/v1/models`, `[STATUS] == 200` |
| Magpie UI | `http://127.0.0.1:3430/`, `[STATUS] == 401` |
| nvirellia.im | `http://127.0.0.1:8081/`, `[STATUS] == 200` |
| Paseo daemon | `http://127.0.0.1:6767/api/health`, `[STATUS] == 200` |
| sing-box | `http://127.0.0.1:9990/version`, `[STATUS] == 200` |
| NetBird tunnel | `tcp://127.0.0.1:18083`, `[CONNECTED] == true` |
| SSH | `tcp://127.0.0.1:22`, `[CONNECTED] == true` |
| Gatus | `http://127.0.0.1:3001/`, `[STATUS] == 200` |

The default interval is 60 seconds. Add an endpoint in the machine definition:

```nix
services.gatus.settings.endpoints = [
  {
    name = "Example";
    group = "neko-sphere";
    url = "http://127.0.0.1:1234/health";
    interval = "30s";
    conditions = [ "[STATUS] == 200" ];
  }
];
```

Each entry is Gatus' own endpoint shape, so conditions such as
`[RESPONSE_TIME] < 500`, `[BODY].status == UP`, certificate expiry and
`client.insecure` are available without a repository-level abstraction.

A TCP endpoint uses the `tcp://` scheme and `[CONNECTED] == true`; `[STATUS]`
does not apply to it. Magpie's UI returns `401` without its sign-in key, so its
condition accepts exactly that code.

## Verification

```sh
systemctl status gatus
curl -s http://127.0.0.1:3001/api/v1/endpoints/statuses \
  | jq -r '.[] | [.key, (.results[-1].success | tostring)] | @tsv'
journalctl -u gatus -b --no-pager
```

The status page is at `https://nsphere-gatus.dwelf-hoki.ts.net/` from a tailnet
device once the Service is defined and the host approved.
